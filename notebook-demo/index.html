notebook demo

Runnable Python in the browser, powered by marimo.

This page is not linked from the site. It is a sandbox for trying runnable notebooks: the Python below runs in your browser through marimo and WebAssembly, with nothing installed and no server behind it. The first run takes a few seconds while Python and the packages load.

Notebooks are reactive. Move a slider and every cell that depends on it reruns. You can also edit the code in place.

Amdahl’s law

How much faster does a program get on more processors when only part of it runs in parallel?

import marimo as mo
import numpy as np
import matplotlib.pyplot as plt

parallel = mo.ui.slider(0.50, 0.99, step=0.01, value=0.95, label="parallel fraction")
max_procs = mo.ui.slider(2, 14, value=10, label="processors (2^n)")
mo.vstack([parallel, max_procs])

procs = 2 ** np.arange(0, max_procs.value + 1)
speedup = 1 / ((1 - parallel.value) + parallel.value / procs)

fig, ax = plt.subplots(figsize=(7, 3.5))
ax.semilogx(procs, speedup, marker="o", base=2)
ax.axhline(1 / (1 - parallel.value), linestyle="--", color="gray")
ax.set_xlabel("processors")
ax.set_ylabel("speedup")
ax.set_title(f"{parallel.value * 100:.0f} percent parallel: speedup can never exceed {1 / (1 - parallel.value):.0f}x")
ax.grid(True, alpha=0.3)

import marimo as mo
name = mo.ui.text(value="EVL", label="Your name")
name

mo.md(f"Hello, **{name.value}**! This line reruns every time you type.")

Writing your own

Add marimo: true to a page’s front matter, then wrap fenced Python blocks in a <div class="al-marimo-inline" markdown="1">. Each block becomes a cell, and all the blocks in one div share a notebook. To embed a notebook saved on marimo.app instead, use {% al_marimo_embed src="https://marimo.app/l/..." %}.
