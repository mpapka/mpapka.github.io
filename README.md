# mpapka.github.io

Personal website of Michael E. Papka.

**Live site:** [mpapka.github.io](https://mpapka.github.io/)

## Site Contents

- **About** - Bio and contact information
- **Projects** - Research projects including SAGE, FOUNT, NAIRR, and others
- **Students** - Current and former students
- **Publications** - Academic publications
- **Teaching** - Courses at UIC and NIU

## Built With

This site is built using [Jekyll](https://jekyllrb.com/) with the [al-folio](https://github.com/alshedivat/al-folio) theme.
